# Templates

Starters that graduated from a study and are ready to copy into a real project.

Nothing has graduated yet. A study earns a place here when:

1. it is `concluded` and its verdict is "use it";
2. the experiment-specific parts (demo data, artificial delays, lesson content) have been removed;
3. it has a README that says what it is for and how to start;
4. it has an `npm run ci` script, so CI keeps checking it.

To start a project from a template, copy its folder without the git history:

```bash
npx degit NayemulSCode/modern-software-rnd/templates/<name> my-project
```
